# AI Parallel v2.1.4

首个公开 GitHub Release，提供可直接解压加载的 Chrome/Edge/Firefox
Manifest V3 扩展包。

## 主要功能

- ChatGPT、DeepSeek、智谱清言、Qwen、Kimi、Claude、Gemini 多面板网页工作区
- Grok 受控顶层标签页模式，保留官网登录状态和 WebSocket 实时连接
- 一次输入，并行发送到已选模型
- Compare Drawer 收集回答并导出 Markdown、JSON 或 `.md` 文件
- Agent Handoff：将比较上下文发送给目标模型
- 本地 Prompt Library

## Grok 兼容性

Grok 的认证页禁止 iframe，且其已登录 WebSocket 在扩展 iframe 中不稳定。此版本不再强行嵌入 Grok，而是复用正常的 `grok.com` 顶层标签页，并通过受限的扩展消息桥执行发送与回答收集。

## 安装

1. 按浏览器下载对应压缩包：
   - Chrome：`ai-parallel-browser-extension-v2.1.4.zip`
   - Edge：`ai-parallel-edge-browser-extension-v2.1.4.zip`
   - Firefox：`ai-parallel-firefox-browser-extension-v2.1.4.zip`
2. 解压 ZIP。
3. 打开对应的扩展管理页：`chrome://extensions/`、
   `edge://extensions/` 或 `about:debugging#/runtime/this-firefox`。
4. 开启开发者模式，点击“加载已解压的扩展程序”。
5. 选择解压后的 `ai-parallel-browser-extension` 文件夹。

## 校验

下载同名 `.sha256` 文件后执行：

```bash
sha256sum -c ai-parallel-browser-extension-v2.1.4.zip.sha256
```

Edge 和 Firefox 的校验文件名与压缩包名称相同，只需替换上述文件名。

## 构建与发布校验

仓库中的 `Release Matrix` workflow 会为 Chrome、Edge、Firefox 分别执行
类型检查、静态检查、单元测试、WXT 构建、Manifest 校验、SHA-256 校验和
ZIP 完整性校验。开发阶段暂不自动执行浏览器加载和登录态 E2E；合并前
由维护者在目标浏览器中完成加载验证，并在需要时运行受保护的认证 smoke。

## 更新

手动更新时覆盖或重新解压到固定目录，然后在扩展管理页点击“重新加载”。Linux 用户也可以下载本 Release 的 `ai-parallel-sync`，安装到 `~/.local/bin/` 后用同名命令同步后续版本。
